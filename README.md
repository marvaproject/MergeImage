## Cara Pakai

1. Klik tombol **Download macOS (.dmg)** di atas.
2. Buka file `.dmg` yang selesai diunduh.
3. Seret ikon **Merge Image** ke folder **Applications**.
4. Buka aplikasinya dan siap digunakan.

---

## Fitur

- **Tata Letak Fleksibel**: Gabungkan gambar ke samping (Horizontal), ke bawah (Vertikal), atau susunan Kisi (Grid).
- **Kustomisasi Border**: Atur ketebalan garis, warna border, dan lengkungan sudut gambar (rounded) sesuai selera.
- **Atur Urutan dengan Seret**: Geser baris gambar ke atas atau ke bawah secara langsung untuk mengubah urutan susunan.
- **Sangat Ringan**: Ukuran aplikasi hanya sekitar 700 KB, hemat memori dan tidak membuat laptop panas.
- **Hasil Kualitas Asli**: Menyimpan gambar dengan resolusi penuh 100% tanpa penurunan kualitas.
- **100% Offline**: Privasi aman tanpa memerlukan koneksi internet.
